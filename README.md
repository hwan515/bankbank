# 통합 금융 서비스 bankbank
은행에 은행에 더하자라는 슬로건을 가지고 출발한 저희 서비스는 예금부터 카드추천까지 다양한 금융 서비스를 경험 할 수 있는 플랫폼입니다.

##  팀 소개 및 역할
#### 팀장: 정지환
역할
- 예적금 데이터 저장, 예적금 목록 조회 및 세부 기능
- 카드 데이터 크롤링
- 카드 추천 시스템 (Chroma DB)
- 챗봇 시스템
- 커뮤니티 기능

#### 팀원: 원대안
- 현물 데이터 시각화
- 근처 은행 검색 기능 및 길 안내
- Youtube API를 활용한 관심 영상 정장
- 채팅 시스템
